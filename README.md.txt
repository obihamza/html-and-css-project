## 🎨 Design

The portfolio follows a simple design system based on:

* Blue primary accent

* Dark navy dark mode
* Rounded cards
* Subtle shadows
* Consistent spacing
* Responsive layouts
* Modern typography

## 📱 Responsive Layout

The website is designed to adapt to different screen sizes.

### Desktop

Two-column layouts are used for sections such as the hero, about, and contact sections.

### Tablet

Content is reorganized and spacing is reduced to provide a comfortable tablet experience.

### Mobile

Sections become vertically stacked, navigation adapts to smaller screens, and cards resize to fit the viewport.
